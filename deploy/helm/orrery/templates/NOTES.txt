Orrery is installed in namespace {{ .Release.Namespace }} (images: {{ .Values.image.registry }}/orrery-*:{{ default .Chart.AppVersion .Values.image.tag }}).

Open the console (API, MCP and docs are served from the same address):
{{- if .Values.ingress.enabled }}
  {{ include "orrery.publicBaseUrl" . }}
{{- else }}
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullname }}-web 8080:{{ .Values.web.service.port }}
  open http://localhost:8080
{{- end }}
{{- if .Values.config.adminToken.enabled }}

Sign in with the admin token:
  kubectl -n {{ .Release.Namespace }} get secret {{ include "orrery.secretName" . }} -o jsonpath='{.data.admin-token}' | base64 -d; echo
{{- end }}
{{- if .Values.config.oidc.issuer }}
Or sign in through {{ .Values.config.oidc.issuer }}.
{{- end }}

CLI (Node.js 20+; served by the install itself) and MCP, with the same token or an API token:
  curl -fsSLo orrery {{ include "orrery.publicBaseUrl" . }}/cli/orrery.mjs && chmod +x orrery
  ./orrery login --url {{ include "orrery.publicBaseUrl" . }} --token <token>
  ./orrery mcp     # MCP client config: {{ include "orrery.publicBaseUrl" . }}/mcp

Give bots a model: in the console, Settings → Agent credentials, set KIRO_API_KEY (Kiro) or a key
such as ANTHROPIC_API_KEY (OpenCode), or add OpenAI-compatible providers (config.providers).
{{- if .Values.temporalServer.enabled }}

Temporal UI: kubectl -n {{ .Release.Namespace }} port-forward svc/{{ $fullname }}-temporal 8233
{{- end }}

Bundled {{ if .Values.postgresql.enabled }}PostgreSQL{{ end }}{{ if and .Values.postgresql.enabled .Values.temporalServer.enabled }} and {{ end }}{{ if .Values.temporalServer.enabled }}Temporal{{ end }} run as single pods. For production use managed
services (config.database, config.temporal) and disable the bundled ones.
{{- end }}
